Version 2.6 – March 30, 2026

🚀 New Features

  • URL Inventory CSV Export: Export all discovered URLs into a structured CSV file for easier analysis, reporting, and integration with external tools.
  • Crawl Coverage Insights: Added detailed crawl coverage information to scan reports, giving better visibility into scanned vs. discovered endpoints.
  • SSRF via Host Header Detection: Introduced a new test for Server-Side Request Forgery (SSRF) through manipulation of the HTTP request host header.

    • --no-discovery

  • Detection Rule Enhancements: Updated vulnerability checks for:

    • Vulnerable Nginx Versions
    • Vulnerable OpenSSL Versions
    • Vulnerable Apache Tomcat Versions
    • Vulnerable WordPress Versions

  • Internal Refactoring: Improved core components for better performance, maintainability, and scalability.

🐛 Bug Fixes

  • General stability improvements and minor fixes across the scanning engine.
