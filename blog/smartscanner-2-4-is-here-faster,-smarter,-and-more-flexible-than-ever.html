🚀 SmartScanner 2.4 Is Here! Faster, Smarter, and More Flexible Than Ever

By SmartScanner 28 November 2025

We’re excited to announce the release of SmartScanner 2.4, delivering powerful new capabilities, smoother workflows, and enhanced vulnerability detection to help you secure your applications more effectively. This update focuses on flexibility, performance, and accuracy, based directly on feedback from our amazing community.

🔐 License Transfers Made Effortless

Until now, moving your SmartScanner license from one machine to another could be inconvenient. With version 2.4, we’ve made this process simple, transparent, and fully self-service.

You can now easily remove your license from one device and activate it on another, giving you complete control, especially valuable for users upgrading hardware or shifting between work environments.

⚙️ Request Rate Limiting for Smarter, Safer Scans

High-speed scanning can sometimes overwhelm sensitive endpoints. SmartScanner 2.4 introduces Request Rate Limiting, allowing you to customize the maximum number of requests per second during a scan.

This gives you better control over:

  • Server impact
  • API rate quotas
  • Performance tuning
  • Stability when scanning fragile applications

Whether you’re testing production, staging, or a personal sandbox, SmartScanner lets you scan at the pace that’s right for you.

🖥️ More Powerful CLI Options

For automation enthusiasts and power users, the CLI (sms.exe) now supports passing a Scan Configuration File. This gives you fully reproducible scans with predefined targets, settings, and preferences, all triggered with a single command.

Perfect for scripting, batch processing, and repeatable workflows.

⚡ Faster & More Accurate Detection

We’ve continued refining SmartScanner’s engine to make it faster and more precise than ever:

Performance Optimizations

  • Improved Chromium-based page evaluation ensures faster loading and fewer heavy operations.
  • Better JavaScript library detection means more accurate fingerprinting of client-side technologies.

Updated Detection Rules

We’ve enhanced vulnerability checks for:

  • Vulnerable Tomcat Versions
  • Vulnerable OpenSSL Versions
  • Vulnerable WordPress Versions

Plus many updated vulnerability definitions to ensure you’re scanning with the most current intelligence.

🎯 A Stronger, Smarter SmartScanner

Version 2.4 brings meaningful improvements across flexibility, performance, and security coverage. Whether you’re a penetration tester, a developer, or a security engineer, this release helps you work more efficiently and detect risks more accurately.
