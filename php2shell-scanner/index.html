Know what you are testing

What is PHP2Shell?

PHP2Shell refers to two critical PHP runtime vulnerabilities: CVE-2026-109618 and CVE-2026-109619. Because the flaws are in PHP itself, they can affect applications on different CMSs and frameworks when those apps use a vulnerable runtime.

The fix depends on the PHP branch and package vendor. A version banner can be misleading when a Linux distribution backports security fixes without changing the upstream version number. Check the package changelog as well as the version reported by your server.

PHP patch guidance

Check the fixed release for your PHP branch.

PHP's upstream security releases include fixes at these versions. If you use distribution-managed PHP, check your package vendor's advisory: a backported fix may use a different version string.

What to do next

A scan is the start of remediation.

If PHP2Shell is detected, inventory all PHP runtimes serving the application, including containers, PHP-FPM pools, workers, and other deployment environments. Upgrade to a PHP release containing the fix or apply a verified vendor backport, then restart the affected PHP services.

Follow the vendor guidance for your operating system and PHP package. Do not treat memory limits or a web application firewall as a replacement for patching. If a vulnerable service was exposed, follow your incident-response process to investigate and protect credentials.

PHP2Shell scanner FAQ

Questions before you scan

Which vulnerabilities does the PHP2Shell scanner check?

SmartScanner checks for CVE-2026-109618 and CVE-2026-109619 using both passive detection and harmless active tests.

Which PHP versions include the upstream fixes?

The PHP 8.5, 8.4, 8.3, and 8.2 branches have fixes in 8.5.12, 8.4.27, 8.3.36, and 8.2.35, respectively. Linux distributions may backport fixes without changing the upstream version number, so check your package vendor's advisory.

What if I use PHP 8.1 or an older branch?

PHP 8.1 and earlier are no longer supported upstream. Check whether your operating-system or hosting vendor provides a security backport. If not, plan an upgrade to a supported PHP branch.

Does SmartScanner scan online?

No hosted scanner runs the test. SmartScanner runs on Windows and sends requests from your computer to the target URL you entered.

Is the PHP2Shell scanner free?

SmartScanner Free includes unlimited scans with no signup or credit card. The Free edition limits vulnerability details; Pro unlocks the full PHP2Shell finding details. See plans and pricing.

Does entering a URL start the scan?

No. The form opens SmartScanner on Windows with your target URL. Choose the PHP2Shell test and start the scan in the app.

Can I scan any website?

Only scan systems you own or have explicit permission to test. Obtain authorization before assessing any third-party application.

What should I do if the scan finds PHP2Shell?

Confirm the finding against the PHP packages and vendor advisories for your environment. Upgrade to a fixed release or apply a verified backport, restart affected services, and run the check again.

Does a clean result prove that every PHP runtime is patched?

No single website scan proves the state of every server, container, worker, or runtime in your environment. Inventory your PHP deployments and verify package updates directly with your vendors.
